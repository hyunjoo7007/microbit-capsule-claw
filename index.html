마이크로비트 V2에 넣는 코드

MakeCode → 새 프로젝트 → JavaScript에 붙여넣고 다운로드하세요. 무선 수신기는 필요하지 않습니다. 장치와 게임은 모두 115200bps를 사용합니다. 기존 9600 코드가 있다면 아래 코드로 다시 다운로드하세요. USB 연결 후 MakeCode 시리얼 창은 닫아주세요. 포트 목록에 장치가 없으면 데이터 USB 케이블과 다른 USB 단자를 확인하세요.

LED가 위를 향하게 평평하게 들고 ‘중심 보정’을 누르세요. A로 집고 B로 캡슐을 엽니다. A+B는 게임 중지, 로고 터치는 새 게임 시작입니다. 중심 보정은 화면 버튼으로 합니다. 로고 터치는 V2 전용입니다. 수신이 0.7초 끊기면 이동·집기를 잠그지만 제한 시간은 계속 흐릅니다.
